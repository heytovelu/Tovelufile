# Tovelu — Towards Better Health

> **Operating Doctrine**: Built under the governance of the [Tovelu Constitution](Tovelu%20Constitution.pdf).  
> **Mission**: Build a globally trusted health-intelligence platform that continuously helps humanity move toward better health.

---

## Tovelu Design System (TDS)

The **Tovelu Design System (TDS)** is the foundational UI/UX layer powering Tovelu. It adheres to:
- **Calm, Human & Scientific** visual language (Article 39)
- **Mobile-First Touch Architecture** with 48px touch targets (Article 40)
- **Zero Fear-Based Visuals** (Article 63)
- **WCAG AAA / AA Accessibility** (Article 42)

### Quick Start (Local Development)

```bash
# Ensure Node 20+ is active
nvm use 20

# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```
